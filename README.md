# Intelligent-Hybrid-Energy-Management-PSV
Arquitetura inteligente de gerenciamento energético para sistemas de propulsão naval híbridos diesel-elétricos, utilizando Inteligência Artificial, redes LSTM, Controle Preditivo Baseado em Modelo e baterias de íons de sódio para otimização do consumo, eficiência e redução de emissões.
